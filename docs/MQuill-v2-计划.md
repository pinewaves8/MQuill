# MQuill v2 计划

## v1 封版结论

**MQuill v1 核心链路已达到可验收状态。**

v1 验证的能力：
- 完整链路跑通：Project → Scene → Draft → Revision → Version → Issue
- 段落级问题定位（paragraphIndex + excerpt）
- 8维度评估 + 问题单 + 修订闭环

v1 已知局限：
- 段落定位准确率 ~70%（Agent paraphrasing 问题）
- 无重复段落检测门禁
- 无发表准备度评估
- 无长篇 Lore/时间线管理

---

## v2 目标定位

**长篇质量稳定化**

v1 验证"能跑通"，v2 验证"跑得好"——稳定输出高质量中长篇作品。

---

## v2 功能清单

### P0 - 必须有（阻塞长篇稳定化）

#### 1. 重复段落检测门禁
**问题**：v1 导出结果存在明显段落重复
**方案**：
- 在修订应用前增加段落级相似度检测
- 相似度阈值：连续 50 字相同 或 Jaccard > 0.7
- 命中门禁时阻断导出，标记问题段落

#### 2. 结构性重复硬指标
**问题**：评估器未识别"换种说法重复同一内容"
**方案**：
- 新增评估维度：段落重复率、意象密度峰值
- Gate 层新增检查项：`structural_repetition`
- 重复段落率 > 5% 时 Gate fail

#### 3. 修订绑定精确段落
**问题**：修订回退到粗粒度（整章/首段）而非精确段落
**方案**：
- `resolveIssueLocationRef` 增强：多策略匹配（excerpt > paragraphIndex > 内容相似度）
- 修订优先段落级替换，强制最低粒度
- 应用修订后自动复评，确认收敛

#### 4. "无默认章节"导入模式
**问题**：基线测试需手动删除默认章节
**方案**：
- `POST /api/projects/:id/chapters/import` 增加 `replaceExisting: true`
- 或项目创建增加 `createDefaultChapter: false`

### P1 - 重要（质量提升）

#### 5. 导出门禁结构化返回
**问题**：导出门禁只返回成功/失败，无法定位问题
**方案**：
- 导出失败时返回 `{ type, chapterId, sample, threshold }`
- 问题分类：字数不足、重复段落、内容空洞

#### 6. 基线报告双层验收
**问题**：只看通过率无法区分"能力问题"和"阈值问题"
**方案**：
- 流程闭环验收层：链路完整性
- 质量门禁验收层：字数、重复率、失败分类
- 两层都过才算基线达标

#### 7. 修订长度门禁混合策略
**问题**：纯比例门禁对短文本过于敏感
**方案**：
- 短文本（<200字）：绝对字数差值门限
- 长文本（>200字）：保留率 + 膨胀率
- `append` 模式单独放宽

### P2 - 增强（长篇专项）

#### 8. Lore 检索增强
**问题**：v1 grounding pack 信息有限
**方案**：
- 增加角色关系图谱检索
- 增加世界观规则冲突检测
- 增加时间线一致性校验

#### 9. 发表准备度独立评估
**问题**：v1 混淆"跑通闭环"和"文学质量达标"
**方案**：
- 新增 `publishability` 评估维度
- 分项打分：语言成熟度、人物辨识度、冲突推进、结构完整、重复痕迹、结尾余韵
- 独立于章节评估，不阻塞流程但独立门禁

#### 10. 角色漂移检测
**问题**：长篇易出现角色性格/行为不一致
**方案**：
- 建立角色特征向量
- 评估时检测角色行为是否符合已有设定
- 发现漂移时提出修订建议

#### 11. 伏笔管理
**问题**：长篇伏笔难以追踪和回收
**方案**：
- 新增伏笔注册 API
- 伏笔提出时记录，评估时检查是否回收
- 未回收伏笔影响 ending_hook 分数
