2.4 Agent调用方式（四大模式，直接套用）
模式一：技法查询（基础调用）
调用触发：输入“查询XX技法”“XX技法是什么”“XX技法怎么用”
返回内容：技法定义、核心要点、古典渊源、现代演化、经典案例（古典+现代）、现代应用建议、相关技法推荐。
示例触发：“查询草蛇灰线·金庸版”
示例返回：（对应金庸版草蛇灰线的完整数据，含定义、要点、天龙八部/笑傲江湖案例、网文应用建议等）
模式二：创作辅助（核心调用）
调用触发：输入创作场景+需求，格式为“我要写XX（场景，如100万字修仙网文/1分钟短剧），需要XX（需求，如设计伏笔/塑造人物群像/调节节奏）”
返回内容：推荐技法组合、具体操作步骤、案例对照、注意事项。
示例触发：“我要写一部100万字的修仙小说，主角后期会黑化，前期如何埋伏笔？”
示例返回：推荐“草蛇灰线·金庸版+倚天不出式悬念”组合，给出3个递进式伏笔设计步骤，对照《天龙八部》萧峰身世案例，提示伏笔要“淡而重复、跨距足够”。
模式三：文本诊断（进阶调用）
调用触发：输入小说片段/剧本片段+诊断需求，格式为“诊断这段文本的技法使用情况，建议补充哪些技法”
返回内容：已用技法识别、技法使用评价、可补充的技法及应用建议、修改示例。
示例触发：“诊断这段网文片段（粘贴片段），看看用了哪些技法，还能补充什么让人物更立体？”
示例返回：识别出已用“烘云托月法”，评价其使用亮点与不足，建议补充“背面铺粉法”和“留白塑人”，给出具体修改方向。
模式四：仿写训练（拓展调用）
调用触发：输入“用XX技法仿写XX场景”“模仿金庸/古龙风格，用XX技法写一段XX（场景，如江湖对决/日常过渡）”
返回内容：仿写示例、技法应用解析、可优化方向。
示例触发：“用古龙的闪电式开局+格言体，写一段短剧开头”
示例返回：仿写片段（“刀光落时，他的剑还在鞘里。‘你输了，’女人的声音像冰，‘输在太相信自己的刀。’”），解析技法应用，提示可增加“留白法”强化氛围。

四、核心应用场景示例（Agent调用参考）
场景1：网文系统流设计（高频需求）
用户需求：“我要写系统流小说，但不想让系统出现太突兀，怎么让系统出现自然，且有长线伏笔？”
Agent调用Skill流程：
1.识别需求：系统出场自然+长线伏笔，适配网文创作场景；
2.匹配技法：推荐“草蛇灰线·金庸版+倚天不出式悬念”组合；
3.生成方案：
        
￮第1-10章：主角反复梦到“古老轮盘”（草蛇灰线第一点，淡笔铺垫），偶尔在危急时刻感受到轮盘的微弱暖意，不解释来源；
￮第15章：主角遭遇致命危机，轮盘实体化，初步激活系统（倚天不出式悬念，延迟出场），仅解锁基础功能，不揭示轮盘来历；
￮第50章：主角接触到上古遗迹，揭示轮盘与上古文明的关联，回收前期伏笔（草蛇灰线回收，意义升级）；
￮第100章：揭示轮盘的终极目的，与主角身世绑定，形成二次回收，推动主线升级。
4.案例对照：《倚天屠龙记》屠龙刀贯穿全书，前期仅作为“武林至宝”铺垫，后期才解密“屠龙刀藏九阳真经”，与方案逻辑一致。
场景2：剧本杀人物设计（新增场景）
用户需求：“剧本杀需要6个人物互相隐瞒身份，怎么设计人物关系和伏笔，让推理更有层次感？”
Agent调用Skill流程：
1.识别需求：人物身份隐瞒+推理层次感，适配剧本杀场景；
2.匹配技法：推荐“古龙悬疑核驱动+金庸多线并行+古典背面铺粉法”组合；
3.生成方案：
        
￮核心悬疑核：设定“谁杀了师父”作为核心谜题，6个人物均有嫌疑，且各自隐瞒与师父的过往恩怨（悬疑核驱动）；
￮多线并行：为每个人物设计独立暗线（如弟子A隐瞒师父夺其武功，弟子B隐瞒师父是其杀父仇人），每条暗线设置1-2个伏笔（多线并行法）；
￮背面铺粉：通过人物对话、道具（如师父的书信、破损的兵器），侧面暗示人物身份，不直接揭露（背面铺粉法）；
￮伏笔回收：游戏中期通过线索卡逐步解锁伏笔，后期所有人物暗线交汇，拼凑出真相（乾坤大挪移结构）。
4.案例对照：《陆小凤传奇》系列，以“青龙会老大是谁”为悬疑核，多个人物隐瞒身份，通过碎片化线索逐步拼凑真相，与方案逻辑一致。
场景3：短视频短剧开头设计（高频需求）
用户需求：“1分钟短剧需要强冲突，怎么开头抓人，快速建立人物关系和核心矛盾？”
Agent调用Skill流程：
1.识别需求：1分钟短剧+强冲突开头+快速建立人物/矛盾，适配短视频场景；
2.匹配技法：推荐“古龙闪电式开局+格言体+一击两鸣”组合；
3.生成方案：

￮开头3秒：镜头对准人物面部特写，台词直接切入冲突：“你杀了我爹，却要我嫁你？”（闪电式开局，快速抓眼球）；
￮中间20秒：快速交代人物关系（女主是仇人之女，男主是杀父仇人），通过一个道具（如父亲的玉佩）强化矛盾（一击两鸣，道具既体现身份，又暗示恩怨）；
￮结尾17秒：女主举刀对准男主，说出金句：“有些债，血也洗不清”（格言体，点睛主题，留下悬念）。
4.案例对照：古龙《多情剑客无情剑》开头“冷风如刀，以大地为砧板，视众生为鱼肉”，直接切入氛围与冲突，与方案的闪电式开局逻辑一致。
