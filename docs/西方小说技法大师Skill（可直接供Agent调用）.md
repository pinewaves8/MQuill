二、SKILL.md 完整内容（Agent调用核心指南）
2.1 技能概述
本Skill整合西方古典小说叙事体系（荷马、塞万提斯、简·奥斯汀等）与近现代主流文学流派技法（现实主义、现代主义、后现代主义、类型小说等），涵盖60+种核心叙事技法，囊括从古典史诗到当代类型小说的全维度创作技巧，形成“古典技法+流派演化+当代应用”的完整体系，辅助Agent高效完成各类叙事创作相关任务，解决视角控制、人物塑造、结构布局、氛围营造等核心创作痛点，兼具学术性与实用性，与“中国小说技法大师Skill”形成互补。
2.2 核心功能
运用荷马、塞万提斯、托尔斯泰、乔伊斯、海明威、博尔赫斯、阿加莎等西方顶级小说大师及各流派的经典技法，辅助现代小说创作、剧本写作、叙事设计、网文创作等，提供技法查询、创作辅助、文本诊断、仿写训练四大核心服务，适配西方风格创作及中西技法融合创作场景。
2.3 可用技法库（60+种，分类呈现，可直接调用）
一、伏笔照应类（核心11种）
•契诃夫之枪（现代·契诃夫）—— 经典伏笔技法，与中式“草蛇灰线”呼应
•环形伏笔（后现代·博尔赫斯）—— 线索闭环，首尾交织
•预言式伏笔（古典·荷马）—— 神谕、预言铺垫后续剧情
•细节伏笔（现实主义·托尔斯泰）—— 以细微动作/道具暗示人物命运
•反转式伏笔（悬疑·阿加莎）—— 伏笔导向意料之外、情理之中的反转
•隐喻式伏笔（现代主义·卡夫卡）—— 以隐喻符号埋伏核心主题
•跨文本伏笔（后现代·卡尔维诺）—— 不同文本间形成呼应
•心理伏笔（现代主义·伍尔夫）—— 以人物心理活动铺垫行为动机
•环境伏笔（现实主义·狄更斯）—— 以环境描写暗示剧情走向
•留白式伏笔（现代·海明威）—— 省略细节，留下暗示性线索
•多线伏笔交织（现代·福克纳）—— 多条线索伏笔相互呼应，构建叙事网络
二、对比衬托类（核心9种）
•人物镜像对比（现代主义·D.H.劳伦斯）—— 设定镜像人物，凸显核心特质
•阶级对比（现实主义·狄更斯）—— 以不同阶级人物的生活对比，揭示社会现实
•善恶对比（古典·塞万提斯）—— 以正邪人物对比，强化主题冲突
•时空对比（后现代·博尔赫斯）—— 不同时空场景对比，构建叙事张力
•理想与现实对比（现实主义·屠格涅夫）—— 人物理想与现实的落差对比
•内心与外在对比（现代主义·乔伊斯）—— 人物外在行为与内心活动的反差
•美丑对比（古典·雨果）—— 外在美丑与内在善恶的反向对比
•个体与群体对比（现代·加缪）—— 个体命运与群体处境的对比，凸显荒诞感
•过去与现在对比（现实主义·托尔斯泰）—— 人物过往与当下的对比，展现成长或沉沦
三、结构布局类（核心10种）
•史诗式结构（古典·荷马）—— 宏大叙事，多人物、多线索交织
•流浪汉结构（古典·塞万提斯）—— 以人物漫游为线索，串联碎片化情节
•意识流结构（现代主义·乔伊斯/伍尔夫）—— 以人物意识流动为叙事脉络
•多视角嵌套结构（后现代·福克纳）—— 多个叙述者视角叠加，构建完整叙事
•环形结构（后现代·博尔赫斯）—— 叙事首尾呼应，形成闭环
•线性时序结构（现实主义·托尔斯泰）—— 按照时间顺序推进，逻辑严谨
•碎片化结构（后现代·卡尔维诺）—— 以碎片化情节拼接，凸显主题
•悬疑式结构（类型·阿加莎）—— 以谜题为核心，逐步解锁剧情
•框架式结构（古典·薄伽丘）—— 以一个核心故事为框架，嵌套多个子故事
•平行结构（现代·海明威）—— 多条平行线索并行，最终交汇
四、节奏控制类（核心8种）
•冰山原则（现代·海明威）—— 藏而不露，以表层细节暗示深层含义，控制叙事节奏
•缓急交替（古典·荷马）—— 史诗战争场景与人物对话场景交替，调节节奏
•悬念递进（类型·柯南·道尔）—— 逐步释放线索，层层递进强化悬念
•心理节奏控制（现代主义·伍尔夫）—— 以人物心理变化控制叙事快慢
•荒诞停顿（现代·卡夫卡）—— 在关键情节处停顿，强化荒诞感与张力
•细节铺陈（现实主义·狄更斯）—— 以细节描写放缓节奏，丰富场景质感
•快速切换（后现代·卡尔维诺）—— 多场景、多视角快速切换，加快叙事节奏
•高潮前置（类型·希区柯克）—— 将核心冲突前置，再逐步回溯原因，把控节奏
五、叙事视角类（核心9种）
•全知全能视角（古典·托尔斯泰）—— 叙述者洞悉所有人物的内心与命运
•有限第三人称视角（现代·海明威）—— 聚焦单一人物视角，保留叙事悬念
•第一人称不可靠视角（现代主义·纳博科夫）—— 叙述者主观片面，误导读者，制造反转
•意识流视角（现代主义·乔伊斯/伍尔夫）—— 以人物内心意识流动为视角核心
•多视角切换（后现代·福克纳）—— 多个叙述者交替叙述，拼凑完整真相
•客观视角（现实主义·莫泊桑）—— 叙述者不介入人物内心，仅客观呈现情节
•元叙事视角（后现代·博尔赫斯）—— 叙述者介入叙事，打破第四堵墙
•书信体视角（古典·简·奥斯汀）—— 以书信形式呈现人物视角与情节
•日记体视角（现代·卡夫卡）—— 以日记形式，展现人物内心世界与叙事推进
六、人物塑造类（核心7种）
•圆形人物塑造（现实主义·E.M.福斯特）—— 人物具有复杂性、多面性，符合现实逻辑
•扁平人物塑造（古典·简·奥斯汀）—— 人物性格单一，突出核心特质，服务于主题
•心理现实主义塑造（现代主义·陀思妥耶夫斯基）—— 以深入的心理描写，展现人物内在冲突
•荒诞人物塑造（现代·卡夫卡/加缪）—— 人物与世界脱节，凸显荒诞主题
•反英雄塑造（后现代·海明威）—— 人物不完美，有缺陷，却具有真实感与感染力
•符号化人物塑造（现代主义·卡夫卡）—— 人物成为某种主题的符号，具有隐喻意义
•成长型人物塑造（现实主义·屠格涅夫）—— 人物在剧情推进中，实现性格与认知的成长
七、意境与风格营造类（核心6种）
•荒诞意境营造（现代·卡夫卡/加缪）—— 通过反常情节与环境，营造荒诞、压抑的氛围
•极简主义风格（现代·海明威）—— 语言简洁克制，不事雕琢，以极简表达深层情感
•魔幻现实主义意境（后现代·马尔克斯）—— 现实与魔幻交织，营造奇幻而真实的氛围
•哥特式意境（古典·爱伦·坡）—— 以黑暗、神秘、惊悚的场景，营造哥特式氛围
•诗意叙事风格（现代·伍尔夫）—— 语言富有诗意，将叙事与抒情结合
•讽刺风格（古典·简·奥斯汀/伏尔泰）—— 以幽默、犀利的语言，讽刺社会现实或人物缺陷
2.4 Agent调用方式（四大模式，直接套用，与中式技法Skill一致）
模式一：技法查询（基础调用）
调用触发：输入“查询XX技法”“XX技法是什么”“XX技法怎么用”
返回内容：技法定义、核心要点、流派渊源、大师实践、经典案例（古典+现代）、现代应用建议、相关技法推荐（含中西技法对比）。
示例触发：“查询契诃夫之枪技法”
示例返回：（对应契诃夫之枪的完整数据，含定义、要点、《变色龙》《万尼亚舅舅》案例、现代悬疑网文应用建议、与中式“草蛇灰线”的对比等）
模式二：创作辅助（核心调用）
调用触发：输入创作场景+需求，格式为“我要写XX（场景，如西方奇幻小说/悬疑短剧），需要XX（需求，如设计悬念/塑造圆形人物/营造荒诞氛围）”
返回内容：推荐技法组合、具体操作步骤、案例对照、注意事项（含中西技法融合建议）。
示例触发：“我要写一部西方悬疑小说，想设计一个反转结局，前期如何埋伏笔？”
示例返回：推荐“契诃夫之枪+阿加莎反转式伏笔+海明威冰山原则”组合，给出3个递进式伏笔设计步骤，对照《东方快车谋杀案》案例，提示伏笔要“隐藏于细节、符合逻辑，与人物动机绑定”，可结合中式“暗线藏锋”技法强化效果。
模式三：文本诊断（进阶调用）
调用触发：输入小说片段/剧本片段+诊断需求，格式为“诊断这段文本的西方技法使用情况，建议补充哪些技法”
返回内容：已用技法识别、技法使用评价、可补充的技法及应用建议、修改示例（可提供中西技法融合修改方案）。
示例触发：“诊断这段西方奇幻片段（粘贴片段），看看用了哪些西方技法，还能补充什么让人物更立体？”
示例返回：识别出已用“史诗式结构+符号化人物塑造”，评价其使用亮点与不足，建议补充“圆形人物塑造+魔幻现实主义意境”，给出具体修改方向，可结合中式“白描”技法简化冗余描写。
模式四：仿写训练（拓展调用）
调用触发：输入“用XX西方技法仿写XX场景”“模仿海明威/博尔赫斯风格，用XX技法写一段XX（场景，如战争场景/奇幻场景）”
返回内容：仿写示例、技法应用解析、可优化方向（含中西技法融合优化建议）。
示例触发：“用海明威的冰山原则+极简主义风格，写一段战争后的场景”
示例返回：仿写片段（“战场静得只剩下风。他低头看着手里的枪，枪身沾着泥。远处，炊烟升起，没人说话。”），解析技法应用（极简语言隐藏战争创伤），提示可结合中式“留白塑人”技法，强化人物内心的隐性表达。
