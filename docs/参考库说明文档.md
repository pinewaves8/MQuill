# MQuill Skill 智能技法套件 · 参考库说明

## 概述

MQuill 参考库是 Skill 智能技法套件的核心组件，为小说创作全流程提供三类对照样本支持。样本以「技法名称 + 经典出处 + 详细描述 + 质量评分」的结构存储，支持按标签、作品、评分等多维度检索。

---

## 三层参考库

### 1. 叙事骨架库（Narrative Framework）

**用途**：大纲结构、情节编排、叙事模式、人物线安排

**当前规模**：19 条样本，76 个标签

**代表样本**：

| 技法 | 出处 | 描述 |
|------|------|------|
| 家族兴衰结构 | 曹雪芹《红楼梦》 | 以家族命运与个人爱情交织，繁华落尽归于苍凉 |
| 三线并行交织 | 金庸《天龙八部》 | 萧峰、段誉、虚竹三线独立发展后合拢于少林寺 |

## 检索接口

### GET /api/skills/reference-library

**查询参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| category | string | `narrative-framework` \| `visual-lens` \| `writing-technique` |
| tags | string | 逗号分隔的标签列表，精确匹配 |
| works | string | 逗号分隔的作品名列表 |
| mode | string | `semantic` \| `keyword` \| `hybrid`（默认 hybrid） |
| limit | number | 最大返回条数（默认 5） |
| minQualityScore | number | 最低质量评分（0-100） |

**返回结构**：


## 在 Skill 执行中的使用

在 `skill-based-workflow.ts` 中，`configureSkills()` 根据小说元数据（类型、标签、风格、目标篇幅）动态生成推荐配置，其中 `reference_examples` 和 `technique_directives` 即从本库检索而来。

各 Skill 的配置注入点：

| Skill | 注入内容 |
|-------|----------|
| outline-skill | 叙事骨架库样本 + 大纲结构技法指令 |
| scene-plan-skill | 画面镜头库样本 + 场景描写技法指令 |
| write-skill | 笔法技法库样本 + 正写作技法指令 |
| evaluate-skill | 笔法技法库样本 + 评估标准 |
| revision-skill | 笔法技法库样本 + 修订技法指令 |

## 质量评分说明

每个样本的 `quality_score` 字段（0-100）反映该技法在其代表作品中的典型性、经典性与教学价值。评分标准：

| 分数段 | 含义 |
|--------|------|
| 98-100 | 该技法在全球文学中的巅峰典范，不可不读 |
| 93-97 | 极具代表性的经典范例，强烈推荐 |
| 88-92 | 高质量的参考样本，推荐阅读 |
| 80-87 | 良好的参考样本，值得参考 |
| < 80 | 辅助参考，可选择性使用 |
