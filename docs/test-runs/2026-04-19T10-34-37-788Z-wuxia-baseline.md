# 燕山雪夜录

## 第一章：雪夜惊变

他想起师弟柳无影，那个总爱笑着说话的少年。他曾将他当作亲兄弟，师父死后，更视其为最后的依靠。可如今，一个字在心头炸开——青崖，让他不得不重新审视一切。

沈寒舟坐在一间简陋的草庐中，窗外雪落无声。屋内烛火微弱，映出他眉间深重的阴影。他的手指轻轻抚过案上一本泛黄的剑谱，那是师父生前最爱的典籍。可此刻，那字迹仿佛也带着某种难以言说的重量。

记忆如潮水般涌来——那夜，雪落满山，师父卧于病榻，气息奄奄。他跪在床前，心中翻涌着不安。师父的目光落在他身上，似有千言万语，却最终只吐出一句：“青崖……”话音未落，便闭上了双眼。

“青崖……”沈寒舟喃喃重复，声音低沉而压抑。师父临终前的这句话，像是一把锋利的刀，划破了他心中早已结痂的伤口。他一直以为，师父的死与寒霜门有关，是他们当年的恩怨所致。可如今，那句“青崖”却让他开始怀疑，事情远没有表面那般简单。

他想起师弟柳无影，那个总是笑眯眯、言语温和的少年。他曾视其为亲兄弟，甚至在师父死后，将他视为唯一的依靠。可如今，那句“青崖”在他心中掀起波澜，令他不得不重新审视一切。

青崖剑派……那是什么？为何师父临终前会提及？难道这其中还藏着什么不为人知的秘密？

沈寒舟握紧拳头，指节发白。他不愿相信，也不愿去想。可心中的疑虑，如同雪夜中的寒风，一点点侵蚀着他原本坚定的信念。

他望着窗外，雪片如刀，割裂了天际。檐角冰棱垂落，似在等待一场决断。忽然，一封密函自风中飘入，落在案头，墨迹未干——是寒霜门的血书。他握紧剑柄，指节发白，心中那道裂痕，终将被鲜血填补。

“师父……”他低声唤道，声音中透着一丝痛楚与迷茫。那一刻，他忽然明白，有些真相，或许比仇恨更可怕。而他，必须找到答案。

夜色如墨，寒风穿林而过，带着雪后的冷冽与沉寂。沈寒舟独坐于一间简陋的茅屋中，手中紧握着那封信，烛光在他脸上投下斑驳的影子，映出眉间深锁的忧虑。

信纸已经泛黄，字迹却依旧清晰有力。他一遍又一遍地读着，仿佛这样就能从字里行间寻得一丝答案。然而，当那两个字——“青崖”——跃入眼帘时，他的心猛然一震。

青崖。

这个名字如同一记重锤，狠狠砸在他的心头。他曾以为，那个名字早已随风而逝，埋葬在过往的尘埃之中。可如今，它竟出现在这封信中，像幽灵般浮现，令他无法忽视。

他站在青崖山巅，剑锋微颤，远处传来寒霜门弟子的呼喝声。记忆如刀，劈开过往——那个曾与他并肩而立的身影，此刻正被血染红。可后来，一切都不复存在。青崖因一场莫名的罪名被逐出师门，从此杳无音讯。

而今，这封信却将他带回了那段尘封的记忆。

沈寒舟的手指微微颤抖，他想起白露曾说过的话：“有些真相，不是你不记得，而是你不敢面对。”此刻，他终于明白其中的意味。

他站起身，走到窗前，望着外面飘落的雪花，心中翻涌着复杂的情绪。是震惊？是愤怒？还是深深的悲哀？

他一直以为自己早已放下仇恨，可如今，那封信中的每一个字都在提醒他：仇恨从未真正消散，只是被压抑在心底，等待一个时机爆发。

他低头再次看向信件，目光落在最后几行字上——“青崖已死，但真相未明。”

沈寒舟的心猛地一沉。青崖死了？可他为何从未听闻？是谁害了他？又是谁，将这封信交到他手中？

他忽然停住，指尖抚过信封边缘的暗纹，那是一道极浅的刻痕，像刀锋划过雪地。这不是普通的信，而是某种讯号。

他深吸一口气，眼中闪过一丝坚定。无论真相如何，他都必须找到答案。因为这一次，他不再只是复仇者，而是一个寻找真相的人。

## 第二章：旧地重游

风雪漫天，天地间一片苍茫。沈寒舟踏着深雪，独自前行，脚步沉稳却透着一丝疲惫。他身披一袭青色长衫，衣角已被寒风撕裂，露出里面暗红的内衬，像是未愈合的旧伤。他的手指缓缓抚过剑柄，指节泛白，仿佛在压抑着什么。目光如霜，落在远处山崖上的一道身影，眼神里翻涌的，是多年未消的恨意。

他手中紧握着一封匿名信，纸张早已被风雪浸得发软，墨迹模糊不清。信中只有一句话：“真相在师父旧居。”字迹潦草，却似有千钧之重。沈寒舟从未相信过江湖上的任何传言，但这一次，他无法忽视。

他曾是青崖剑派的弟子，师承一代宗师，剑法凌厉如霜。可十年前，一场突如其来的变故，让整个门派一夜之间覆灭。他侥幸逃生，却再未回过那片山林。如今，他终于踏上归途，不是为了复仇，而是为了寻找那个被尘封的真相。

雪落无声，只有靴底与积雪摩擦的沙沙声。他走过曾经熟悉的山路，每一步都仿佛踩在记忆之上。远处的山峦隐没于风雪之中，如同他心中那道无法逾越的阴影。

他想起师父临终前的神情，那是一种无奈，也是一种决绝。那时的他年少轻狂，不懂何为恩怨，更不知背后隐藏的阴谋。直到如今，才明白，有些仇恨，不过是他人布下的棋局。

风雪渐急，他放缓脚步，抬头望向远方。一座破败的院落隐约可见，那是师父的旧居，多年未曾有人踏足。他心中泛起一丝莫名的悸动，仿佛有什么正在等待他。

他深吸一口气，迈步向前。雪，依旧在下，而他的心，却渐渐清晰。或许，这一路的风雪，不只是寒冷，更是他内心的一场洗礼。

他站在山崖边缘，风卷起衣角，像一柄悬在头顶的刀。他知道，前方等待他的不是生路，而是宿命。可即便如此，他仍不能退。沈寒舟握紧剑柄，指节发白，心里却比刀锋更冷。他曾以为江湖恩怨不过是一场浮云，如今才知，那不过是未落的雪，压在心头，沉得让人喘不过气。真相，终究要面对。

竹林旧地，风过无痕，唯有竹叶沙沙作响，似在低语往昔。沈寒舟缓步而行，脚下的落叶被踩出细微的脆响，仿佛岁月在此处留下了不可磨灭的痕迹。他站在那片熟悉的竹林前，目光沉静如水，却难掩内心的波澜。

这里是他师父生前居住的地方，如今却空无一人，只有风吹过竹梢，带起一阵阵幽冷的寒意。沈寒舟缓缓走近，四周寂静无声，仿佛时间在这里凝固，连空气都变得沉重起来。他的脚步声在空旷中回荡，像是某种无形的召唤，将他引向更深的林间。

他停下脚步，望着眼前那座破败的竹屋。屋檐下挂着一块残破的匾额，字迹斑驳，已难以辨认。但沈寒舟仍能感受到那股熟悉的气息——那是师父的气息，沉稳、坚定，却又带着一丝不易察觉的孤寂。

他轻轻推开吱呀作响的木门，屋内尘土飞扬，空气中弥漫着一股陈旧的木香。他环顾四周，墙上还挂着几幅泛黄的字画，笔锋遒劲，字里行间透着师父的傲骨与风骨。沈寒舟的手指抚过那些字画，心中涌起一阵复杂的情绪。他曾在这里度过无数个日夜，听师父讲剑道，论江湖，却从未想过，有朝一日会独自站在这里。

忽然，一阵风掠过竹林，带来一丝异样的气息。沈寒舟眉头微皱，眼神警觉。他隐隐觉得，这地方并不如表面那般平静。他缓缓转身，目光投向林深处，那里似乎有一道影子一闪而过，转瞬即逝。

他没有言语，只是静静地站在原地，仿佛在等待什么。竹林依旧寂静，但他知道，有些事情，终究无法逃避。而他，也终于来到这里，面对那段尘封已久的往事。

寒风穿林，竹叶簌簌作响。沈寒舟的脚步在泥泞中留下深浅不一的痕迹，他眉间凝着一层霜色，目光却锐利如刃。这片竹林，是他追踪线索的终点。

密室藏于一处断崖之下，被藤蔓与青苔掩覆，若非白露昨夜指点，他恐怕难以寻到。此刻，他推开半掩的石门，一股陈腐的气息扑面而来，仿佛岁月在此停滞。

残垣裂壁间，风穿隙而过，卷起满地碎纸。木梁斜插，尘土簌簌，几页泛黄笔记在阴影中翻飞，仿佛亡魂低语。沈寒舟蹲下身，指尖轻抚那些泛黄的纸页，字迹潦草，似是匆忙中写就。

“寒霜门暗中勾结西域魔教……”他念出一句，心头猛然一震。这正是师父生前调查的真相，而他一直以为，那只是江湖传言。

他继续翻阅，一张旧纸被他拾起，上面画着一幅简略的地图，标注着几处隐秘据点。他的呼吸微微一滞——这些地点，竟与当年青崖剑派灭门案有关。

记忆如潮水般涌来，师父临终前的神情，师兄弟们的惨状，还有那句未说完的话：“不是他们……是……”他猛地攥紧纸张，指节发白。

风从洞口灌入，卷起满地尘埃，也吹动了他衣袖下的伤痕。那是雪夜渡口留下的印记，如今却成了他寻找真相的钥匙。

他猛然起身，手指扣住石门边缘，指节发白。门后传来风声，混着一丝若有若无的血腥气。他眯眼凝视，暗红苔痕在石缝间蜿蜒，像一条未干的血迹，直指深处。他知道，自己已无路可退。仇恨与真相交织成网，而他必须亲手撕开。

沈寒舟将笔记收起，转身离去。竹林依旧寂静，唯有风声低语，仿佛在诉说一个被遗忘的真相。他脚步坚定，背影冷峻，却掩不住眼底那一抹沉痛。
